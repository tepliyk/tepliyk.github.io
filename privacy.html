Privacy policy

Last updated: 3 October 2026.

AstroHub is a single-user tool run by its owner on the owner's own computer. It is not offered to the public and has no other users.

What data is accessed

  • With the owner's consent, AstroHub uses the YouTube Data API to upload the owner's own videos to the owner's own channel (scope youtube.upload) and to read basic channel and video statistics such as view and like counts (scope youtube.readonly).
  • No data of other YouTube users is collected, stored or processed.

Storage and sharing

  • OAuth tokens and statistics are stored only locally on the owner's computer.
  • No data is sold, shared with or transferred to third parties.
  • Access can be revoked at any time at myaccount.google.com/permissions.

AstroHub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. AstroHub uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
